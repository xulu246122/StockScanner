# 美股 RSI 查询、筛选与预警 App (US Stock RSI Scanner & Alert)

一个“简约、极速、实用、低成本、容易维护”的美股技术指标扫描与智能预警全栈应用。专注于 Wilder RSI(14) 经典算法指标，帮助交易者在 10 秒内锁定市场超卖与超买机会。

---

## 核心功能

1. **股票 RSI 实时/延迟查询**：输入 `NVDA`、`AAPL`、`TSLA` 等美股代码，展示实时报价、涨跌幅、市值、Wilder RSI 数值与状态标签（超卖 / 偏弱 / 中性 / 超买），支持 6/9/14/21/30 周期切换。
2. **RSI 股票多维度筛选器 (Screener)**：
   - 交易所筛选：`NYSE`、`NASDAQ`、`全部`
   - 市值门槛：`全部`、`> $1B`、`> $5B`、`> $10B`、`> $50B`、`> $100B`
   - RSI 快速条件：`RSI < 20`、`RSI < 25`、`RSI < 30`、`RSI < 35`、`RSI > 70`、`RSI > 75`、`RSI > 80`
   - 自定义 RSI 范围（如 20 ~ 30）
   - 多列排序与高性能分页表格
3. **一键超卖扫描入口**：首页直接提供极值超卖快捷入口，一秒扫描全市场跌透标的。
4. **股票详情与多周期图表**：
   - Wilder RSI 历史走势图（标绘 30 超卖线、50 中轴线、70 超买线与色彩渲染阴影区）
   - 股价历史走势图（日线收盘价与成交量）
   - 30 天 / 90 天 / 180 天时间跨度切换
5. **自选股监控 (My Watchlist)**：一键增删关注股票，实时同步最新 RSI 及预警生效标识。
6. **RSI 条件预警与通知引擎 (Alerts Hub)**：
   - 支持 $RSI \le 30$（超卖）、$RSI \ge 70$（超买）、跌破 30、突破 70 及自定义阈值
   - 后台 Scheduler 定期检测与单点一键即时扫描
   - 原生浏览器 Push Notification 弹窗与柔和音频提示音
7. **美股交易时钟**：统一采用美东时间（America/New_York）计算盘前、盘中、盘后、休市与周末状态。

## 核心技术架构

```
美股数据 API / Yahoo Finance
          ↓
 Market Data Provider (带智能 LRU/TTL 缓存与容灾引擎)
          ↓
  RSIService (后端统一计算经典 Wilder 平滑移动平均)
          ↓
  Screener & Alert Scheduler (轮询与规则状态判定)
          ↓
 Web Push Notification & React + Vite 前端交互
```

## 本地运行与测试

### 1. 启动服务
```bash
npm run dev
```
开发服务器将运行在 `http://localhost:3000`。

### Windows 浏览器测试预览

需要 Node.js 18 或更高版本，并已安装项目依赖。双击项目根目录中的 `run-test-preview.cmd` 启动本地源码测试版；看到 `Test preview is ready` 后，在浏览器打开 `http://127.0.0.1:3000`。保持启动窗口开启，按 `Ctrl+C` 停止服务。此预览只绑定到本机回环地址，不会向局域网开放。

若启动器提示缺少依赖，请在项目目录运行 `npm.cmd ci`，安装完成后重新启动。该测试方式直接使用 Node.js 和项目内的 TSX CLI，不需要先打包 Electron 桌面程序。

`release` 目录中的桌面 `.exe` 未配置代码签名，Windows Smart App Control 可能会阻止它。此浏览器测试预览不需要运行该 `.exe`，也不需要关闭或绕过 Windows 安全保护。正式分发桌面版本时，应使用受信任的代码签名证书签名。

### 2. 运行自动化测试套件
```bash
npx tsx test/runTests.ts
```
测试内容涵盖：
- Wilder RSI 平滑算法准确性测试（严格单调递增/递减、横盘与经典序列）
- 股票筛选器条件匹配与分页测试
- 预警规则创建与后台轮询事件测试
